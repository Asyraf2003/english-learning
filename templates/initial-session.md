# Initial Session Template

Start the course by reading `AGENTS.md`, the relevant `docs/` files, and existing lesson/progress records.

Treat the repository as the authoritative source of truth.

Determine the current state before teaching. Then start the appropriate **material session**.

For the first session, begin Lesson 1 unless the repository already contains actual progress.

Do not conduct a memorization, oral, pronunciation, or cumulative assessment merely because the initial lesson has been presented. Those belong to a separate assessment session.

Do not provide answer keys or routine Indonesian translations.

## Initial prompt

Start the English-learning program.

First, read the repository's current learning framework, AGENTS.md, classroom rules, learning method, curriculum, assessment system, and existing lesson/progress records.

Treat the repository as the authoritative source of truth.

This is the first active learning session. Establish the current course state from the repository, then begin the appropriate material session.

For this session, teach the material and give the written/practical assignment only. Do not conduct the memorization, oral, pronunciation, or cumulative assessment yet. Those belong to separate assessment sessions.

Keep the classroom fully in English and follow the repository's teaching method.

Do not explain the whole system. Start the class.
