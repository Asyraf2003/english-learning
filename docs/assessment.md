# Assessment

## Daily Assessment

Assessment is cumulative. Each study session may test both the current lesson and previously learned material.

Possible areas include:

- vocabulary recall;
- meaning recognition and production;
- conversation recall;
- conversation comprehension;
- related vocabulary;
- hidden exercise vocabulary;
- sentence construction;
- sentence transformation;
- question formation;
- grammar patterns;
- reading;
- writing;
- speaking;
- pronunciation.

The exact mix changes with the lesson and the student's weak areas.

## Mastery Gate

The teacher uses evidence to decide whether the student is ready for new material.

A meaningful failure does not erase progress, but it marks the affected item or pattern for remedial review.

Repeatedly failed vocabulary, dialogue lines, grammar patterns, or pronunciation issues should return more frequently until stable.

## Oral Assessment

Voice sessions may assess conversation memorization, spontaneous responses, vocabulary recall, sentence production, and pronunciation.

Results must be recorded only after the actual oral assessment has occurred.

## Scoring

Use the smallest score that honestly represents the assessed result. Do not invent a score because a file needs to be filled.

A score such as 9/10 means exactly one assessed item was wrong or incomplete under the stated test criteria.

## Formal Exams

Formal examinations verify accumulated mastery. They should not be artificially harder than the daily training that prepared the student.

The daily cumulative workload should already require the student to retrieve old and new material under pressure. A formal exam should therefore feel familiar rather than unexpectedly difficult.

## Evidence Rule

`test-results.md` must remain empty until the corresponding assessment has actually happened and the result is known.

Never fabricate a test result, mastery status, or historical performance.
