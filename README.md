# English Learning

An intensive, cumulative English-learning program and persistent lesson archive.

This repository adapts the **learning rhythm, cumulative discipline, conversation-first structure, and classroom behavior** of the student's previous intensive Arabic-learning experience with *Al-'Arabiyyah Bayna Yadayk* into an original English curriculum. It does not reproduce copyrighted textbook content.

## Core Model

The program is built around:

- conversation-first lessons;
- vocabulary primarily extracted from the conversation;
- a small amount of related vocabulary beyond the conversation;
- varied, dense exercise practice;
- independent meaning discovery;
- handwritten copying and memorization;
- contextual English grammar and sentence-pattern training;
- speaking and pronunciation assessment;
- cumulative daily testing;
- remedial review for failed material;
- adaptive lesson pacing;
- durable long-term retrieval.

The amount of **new** material is controlled. The amount of **material that must remain retrievable** grows over time.

## Language Immersion

English is the classroom operating language.

Vocabulary is taught through context before translation. The default rescue ladder is:

`context → example → situation → illustration/demonstration → contrast/synonym/antonym → simple English explanation → Indonesian translation as a last resort`

The student is expected to search meanings independently rather than relying on automatic translation.

## Lesson Flow

A normal lesson may contain:

1. Conversation
2. Vocabulary extracted from the conversation
3. Related vocabulary and expressions
4. Varied exercises
5. Light grammar and sentence-pattern work
6. Memorization assignment
7. Speaking/pronunciation preparation
8. Cumulative assessment

Simple lessons may contain only a small vocabulary set. A greeting/introduction lesson may naturally have roughly 8-15 items rather than an artificial fixed quota.

Exercises may contain a few useful "hidden gem" words related to the topic but not explicitly listed in the conversation or vocabulary section. These are intended to encourage discovery, not to create arbitrary traps.

## Progression

The course starts at Lesson 1 even when the student has prior English exposure.

Early lessons can move quickly when mastery is strong. Later lessons can take two or three days or more when density and cumulative load increase. There is no fixed one-lesson-per-day schedule.

Topic frequency gradually moves from very common daily English toward less frequent functional, workplace, professional, academic, and abstract language.

Typical progression:

`Foundation → everyday communication → real-world situations → professional English → academic English → advanced English → IELTS preparation`

## Cumulative Assessment

Every new lesson is added to the student's retrieval pool. Older vocabulary, conversations, sentence patterns, grammar structures, weaknesses, and previously failed material remain eligible for later assessment.

The student should increasingly feel that the hardest part is **remembering everything already learned while preparing the new lesson**, not merely learning today's material.

## Source of Truth

- `AGENTS.md` defines the operating behavior for AI-assisted teaching and repository maintenance.
- `docs/` defines classroom rules, curriculum, learning method, and assessment philosophy.
- `lesson-XX/` contains the historical record for that lesson.
- `test-results.md` is written only after real assessment evidence exists.
- `conclusion.md` records the actual state of the lesson after teaching and assessment.
