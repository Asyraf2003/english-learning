# English Learning

An intensive, cumulative English-learning curriculum and progress archive.

This project adapts the **learning rhythm and classroom discipline** of the student's previous *Al-'Arabiyyah Bayna Yadayk* experience into English. It is not a copy of the book's copyrighted content.

## Learning Model

- Conversation-first lessons
- Vocabulary primarily extracted from conversation
- Small amounts of related vocabulary beyond the dialogue
- Varied exercises
- Independent meaning discovery
- Handwritten copying and memorization
- Contextual grammar and sentence-pattern practice
- Speaking and pronunciation checks
- Cumulative daily examinations
- Remedial review for failed material
- Adaptive lesson pacing
- Long-term retention through recurring review

## Source of Truth

- `docs/` defines the learning system.
- `bab-XX/` contains the historical lesson record.
- `hasil-tes.md` is populated only after an actual assessment.
- `kesimpulan.md` records the final state of that chapter.
